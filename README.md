# 饰品交易账本

面向 BUFF、悠悠有品、Steam 的个人饰品交易账本，支持 macOS 本机归档与 iOS 随身查阅。

[访问官网](https://www.suag.top/) · [官网源码与维护说明](website/README.md)

- 三平台交易统一归档，查看个人买卖历史。
- 分别呈现现金投入、持仓与已实现收益。
- Mac 负责归档和分析，iPhone 随时查阅自己的云端快照。
- 平台会话保存在本机，客户端专注只读记录与统计。

官网包含真实 Mac 与 iPhone 应用截图，平台身份隐藏，财务数字经所有者授权展示。官网通过 GitHub Pages 发布，HTTPS 由 GitHub 自动管理。
