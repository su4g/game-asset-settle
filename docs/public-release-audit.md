## 安装包与边界

Release 提供 macOS arm64 ZIP、iOS unsigned IPA、纯代码云端包与 SHA-256。应用包不附带任何个人数据库或云连接；iOS 需使用安装者自己的 Apple 账号签名，macOS 未进行 Apple Developer ID 公证。
