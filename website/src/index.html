你可能还想了解

这是 BUFF、悠悠或 Steam 的官方软件吗？+

这是面向个人饰品玩家的独立项目，与 BUFF、悠悠有品、Steam 及其运营方无隶属关系。平台名称与图标用于标识交易记录来源。

macOS 和 iOS 分别负责什么？+

macOS 客户端负责本人平台交易的只读采集、本机归档与统计。iOS 客户端通过连接文件读取你配置的云端快照，查看最后上传的数据；手机端不直接采集平台交易。

在哪里了解项目与版本信息？+

前往 GitHub 项目仓库查看文档、版本信息与更新记录，也可以通过 Issues 反馈问题或提出建议。

持仓估值也算作已经赚到的钱吗？+

持仓估值、Steam 未提现余额与已实现收益分别展示。收益统计以实际交易与可靠成本依据为基础；金额、来源或历史不完整时会保留缺项。
